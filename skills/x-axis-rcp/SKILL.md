# X-axis RCP

Use this skill when a human or AI needs a local X-axis stub/signature census.

Commands:
- `xi-io x scan <workspace>`
- `xi-io x rcp <workspace>`

Consume JSON fields `denominator`, `duplicate_groups`, `unique_artifacts`, and `receipt_digest`. Quantize duplicate structural signatures. Fractalize only unique/distinct candidates.

Never promote an RCP to runtime authority. `RCP != LIVE`.
