# ROTFL command alias

`ROTFL` is a mnemonic alias for the existing `cadence.continue` semantic owner. It does not create a second scheduler, renderer, Reaper, or authority plane.

The command is intended to make the existing continuation lifecycle memorable:

`current projection -> qualify -> Result/RETURN -> REAP/EAT -> backlog refresh -> continue`

Render-on-the-fly consumers may use the current projection as input, but `ROTFL` itself does not grant render, provider, deployment, mail, legal, or mutation authority.

Hard:

- `ROTFL_ALIAS != SECOND_SCHEDULER`
- `ROTFL_ALIAS != EFFECT_AUTHORITY`
- `REAP != DELETE`
- `EAT != PROVIDER_EFFECT`
- `RESULT != RETURN != APPLY_RETURN`
- `PASS != STOP`
